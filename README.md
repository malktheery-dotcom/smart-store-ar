# 🛒 متجر بوسلطان (Bousultan Store)

متجر إلكتروني عربي متكامل وعصري، مبني بتقنيات الويب الأساسية الصافية (**Pure HTML5**, **CSS3**, **Vanilla JavaScript**) بدون أي مكتبات أو أطر عمل خارجية. يتميز بتصميم أنيق يدعم اتجاه اليمين إلى اليسار (**RTL**) بالكامل، ومتجاوب مع جميع أحجام الشاشات (الهواتف الذكية، الأجهزة اللوحية، وأجهزة الكمبيوتر).

---

## ✨ المميزات الرئيسية للمتجر

### 1. واجهة مستخدم عصرية وسريعة (RTL First)
- دعم كامل وأصيل للغة العربية واتجاه اليمين لليسار (`dir="rtl"`).
- خط عربي حديث وجذاب (**Cairo** من Google Fonts).
- تدرجات لونية هادئة وبطاقات بظلال ناعمة وتأثيرات حركية دقيقة (Micro-interactions).
- متجاوب تماماً مع مختلف أحجام الشاشات باستخدام CSS Grid و Flexbox.

### 2. استعراض وتصفية المنتجات والبحث الفوري
- **تصنيفات تفاعلية**: تصفية فورية حسب الأقسام (إلكترونيات، عطور، أزياء، إكسسوارات).
- **بحث فوري (Live Search)**: إمكانية البحث بالاسم، الوصف، أو المميزات مع تحديث تلقائي للنتائج.
- **بطاقة المنتج**: تحتوي على صورة عالية الجودة، شارة التصنيف، نسبة الخصم، السعر الحالي والقديم، وزر إضافة فوري للسلة.

### 3. سلة مشتريات جانبية منزلقة مع نظام كوبونات الخصم
- لوحة جانبية سلسة تنبثق مع خلفية معتمة (`Backdrop Blur`).
- **نظام كوبونات الخصم التفاعلي**: حقل مخصص داخل السلة لإدخال كود الكوبون، مع تطبيق فوري للخصم المئوي وعرض شارة الكوبون مع خيار الإلغاء.
- عداد تفاعلي متحرك على أيقونة السلة في الهيدر يوضح إجمالي العناصر.
- إمكانية زيادة أو تقليل كميات المنتجات أو حذف أي منتج بنقرة واحدة.
- حساب تلقائي وفوري للمجموع الفرعي، قيمة الخصم المقتطعة، والمجموع الإجمالي.
- حفظ تلقائي لمحتويات السلة في `LocalStorage` لمنع فقدان البيانات عند تحديث الصفحة.

### 4. إتمام الطلب المباشر عبر واتساب (WhatsApp Checkout)
- نافذة منبثقة (Modal) مخصصة لجمع بيانات العميل:
  - الاسم الكامل.
  - رقم الهاتف / الواتساب.
  - المدينة والعنوان بالتفصيل.
  - أي ملاحظات إضافية.
- صياغة رسالة واتساب منسقة باحترافية بـ Markdown تشمل:
  - رقم الطلب وتاريخه.
  - بيانات العميل والعنوان.
  - قائمة بالمنتجات المطلوبة وكمياتها وأسعارها الفردية.
  - بيانات كوبون الخصم ونسبة وقيمة الخصم المقتطعة إن وُجدت.
  - المبلغ الإجمالي النهائي بعد الخصم.
- توجيه مباشر إلى تطبيق أو ويب واتساب برابط مشفر بنقرة زر واحدة.

### 5. لوحة تحكم إدارية متكاملة ومحمية (`admin.html`)
- **حماية برمز مرور (PIN Lock Screen)**: شاشة أمان عند فتح لوحة التحكم تطلب رمز المرور (الرمز الافتراضي: `1234`) مع زر لتغيير الرمز وحفظه في `LocalStorage`، وزر لقفل اللوحة في أي وقت.
- **قسم إعدادات المتجر العامة**: إمكانية تعديل رقم الواتساب الذي يستقبل الطلبات وتحديد رمز أو اسم العملة (مثل `ر.س`، `$`) وتُطبّق التغييرات لحظياً في المتجر وسلة الشراء ورسائل الواتساب.
- **قسم إدارة كوبونات الخصم**: نموذج مخصص لإنشاء كوبونات ترويجية بنسب مئوية محددة مع جدول لعرض الكوبونات الفعالة وإمكانية حذفها.
- **إضافة منتجات جديدة**: نموذج إدخال سريع مع ميزة المعاينة الحية لرابط الصورة قبل الحفظ.
- **تعديل المنتجات**: إمكانية تعديل أي منتج وتحديث بياناته فوراً.
- **حذف المنتجات**: حذف المنتج مع نافذة تأكيد لمنع الحذف بالخطأ، وتحديث السلة تلقائياً.
- **إحصائيات فورية**: عرض عدد المنتجات الكلي، عدد التصنيفات، ومتوسط الأسعار.
- **بحث وتصفية في الجدول**: للوصول السريع لأي منتج.
- **استعادة الافتراضيات**: زر مخصص لاستعادة المنتجات النموذجية الـ 6 بضغطة واحدة لأغراض التجربة.
- **مزامنة فورية (Multi-tab Sync)**: استخدام حدث `Storage API` لتحديث صفحة المتجر فور تعديل الإعدادات أو المنتجات أو الكوبونات في لوحة التحكم حتى بدون إعادة تحميل الصفحة يدوياً.

## 🚀 طريقة التشغيل

المشروع مبني بأسلوب **Zero Configuration** ولا يحتاج لتثبيت أي حزم أو خوادم معقدة:

1. قم بتنزيل أو استنساخ المستودع:
   ```bash
   git clone https://github.com/malktheery-dotcom/smart-store-ar.git
   ```
2. ادخل إلى مجلد المشروع:
   ```bash
   cd smart-store-ar
   ```
3. افتح ملف `index.html` في أي متصفح ويب حديث (Chrome, Firefox, Safari, Edge) بالنقر المزدوج عليه.
4. للوصول إلى لوحة التحكم، انقر على زر **"لوحة التحكم"** في أعلى الصفحة أو افتح ملف `admin.html` مباشرة.

## ⚙️ التخصيص والإعدادات

يمكنك تخصيص المتجر بسهولة عبر فتح ملف `script.js` وتعديل كائن الإعدادات في البداية:

```javascript
const CONFIG = {
  STORE_PHONE: "966501234567", // قم بوضع رقم هاتف المتجر بالصيغة الدولية بدون (+)
  CURRENCY: "ر.س",            // العملة المعروضة في المتجر
  PRODUCTS_KEY: "smartstore_products", // مفتاح تخزين المنتجات في LocalStorage
  CART_KEY: "smartstore_cart"          // مفتاح تخزين السلة في LocalStorage
};
```

## 🛠️ التقنيات المستخدمة

- **HTML5**: بناء هيكلي دلالي متوافق مع معايير الويب وقارئات الشاشة.
- **CSS3**: استخدام متغيرات CSS (Variables)، Flexbox، CSS Grid، وتأثيرات حركية خفيفة.
- **JavaScript (ES6+)**: كتابة كود تفاعلي نقي للتحكم بالواجهة، وإدارة الحالة (State).
- **Supabase Cloud Database**: قاعدة بيانات سحابية متكاملة لربط ومزامنة المنتجات والإعدادات والكوبونات لحظياً عبر الـ CDN.
- **WhatsApp Click to Chat API**: ربط الطلبات مباشرة بواتساب من دون الحاجة لباك إند.
- **Google Fonts (Cairo)**: طباعة عربية عصرية واضحة.
