# 🛒 متجر بوسلطان (Bousultan Store)

متجر إلكتروني عربي متكامل وعصري، مبني بتقنيات الويب الأساسية الصافية (**Pure HTML5**, **CSS3**, **Vanilla JavaScript**) بدون أي مكتبات أو أطر عمل خارجية. يتميز بتصميم أنيق يدعم اتجاه اليمين إلى اليسار (**RTL**) بالكامل، ومتجاوب مع جميع أحجام الشاشات (الهواتف الذكية، الأجهزة اللوحية، وأجهزة الكمبيوتر).

---

## ✨ المميزات الرئيسية للمتجر

### 1. واجهة مستخدم عصرية وسريعة (RTL First)
- دعم كامل وأصيل للغة العربية واتجاه اليمين لليسار (`dir="rtl"`).
- خط عربي حديث وجذاب (**Cairo** من Google Fonts).
- تدرجات لونية هادئة وبطاقات بظلال ناعمة وتأثيرات حركية دقيقة (Micro-interactions).
- متجاوب تماماً مع مختلف أحجام الشاشات باستخدام CSS Grid و Flexbox.

### 2. استعراض وتصفية المنتجات والبحث الفوري
- **تصنيفات تفاعلية**: تصفية فورية حسب الأقسام (إلكترونيات، عطور، أزياء، إكسسوارات).
- **بحث فوري (Live Search)**: إمكانية البحث بالاسم، الوصف، أو المميزات مع تحديث تلقائي للنتائج.
- **بطاقة المنتج**: تحتوي على صورة عالية الجودة، شارة التصنيف، نسبة الخصم، السعر الحالي والقديم، وزر إضافة فوري للسلة.

### 3. سلة مشتريات جانبية منزلقة مع نظام كوبونات الخصم
- لوحة جانبية سلسة تنبثق مع خلفية معتمة (`Backdrop Blur`).
- **نظام كوبونات الخصم التفاعلي**: حقل مخصص داخل السلة لإدخال كود الكوبون، مع تطبيق فوري للخصم المئوي وعرض شارة الكوبون مع خيار الإلغاء.
- عداد تفاعلي متحرك على أيقونة السلة في الهيدر يوضح إجمالي العناصر.
- إمكانية زيادة أو تقليل كميات المنتجات أو حذف أي منتج بنقرة واحدة.
- حساب تلقائي وفوري للمجموع الفرعي، قيمة الخصم المقتطعة، والمجموع الإجمالي.
- حفظ تلقائي لمحتويات السلة في `LocalStorage` لمنع فقدان البيانات عند تحديث الصفحة.

### 4. خيارات وطرق الدفع المتعددة وإتمام الطلب عبر واتساب (Payment Methods & Checkout)
- **دعم طرق الدفع المتعددة المرنة**:
  - **الدفع عند الاستلام (COD)**: السداد نقداً أو بالشبكة عند استلام الشحنة.
  - **التحويل البنكي / المحافظ الإلكترونية**: عرض أرقام الحسابات البنكية والآيبان والمحافظ المعتمدة مع زر "نسخ سريع" لتسهيل العملية على العميل.
  - **حقل إجباري لرقم الحوالة**: عند اختيار التحويل البنكي، يُلزم العميل بإدخال رقم عملية التحويل أو اسم المحول للتحقق.
- **حفظ الطلبات سحابياً في جدول `orders` داخل Supabase**:
  - يتم تسجيل وتخزين بيانات الطلب كاملة (العميل، الهاتف، العنوان، المنتجات، الإجمالي، طريقة الدفع، رقم الحوالة، والحالة) سحابياً أولاً والحصول على رقم الطلب المرجعي التلقائي.
- **نافذة منبثقة (Modal) مخصصة لتأكيد الطلب**:
  - الاسم الكامل، رقم الهاتف / الواتساب، والمدينة والعنوان بالتفصيل، وأي ملاحظات خاصة.
- **صياغة رسالة واتساب منسقة باحترافية بـ Markdown تشمل**:
  - رقم الطلب المرجعي السحابي وتاريخه وتوقيته.
  - بيانات العميل والعنوان والملاحظات.
  - قائمة بالمنتجات المطلوبة وكمياتها وأسعارها الفردية.
  - بيانات كوبون الخصم ونسبة وقيمة الخصم المقتطعة إن وُجدت.
  - طريقة الدفع ورقم الحوالة أو اسم المحول (في حال التحويل البنكي).
  - المبلغ الإجمالي النهائي بعد الخصم.
- توجيه مباشر إلى تطبيق أو ويب واتساب بنقرة زر واحدة.

### 5. لوحة تحكم إدارية متكاملة ومحمية (`admin.html`)
- **حماية برمز مرور (PIN Lock Screen)**: شاشة أمان عند فتح لوحة التحكم تطلب رمز المرور (الرمز الافتراضي: `1234`) مع زر لتغيير الرمز وحفظه، وزر لقفل اللوحة في أي وقت.
- **قسم إعدادات المتجر العامة وطرق الدفع**:
  - إمكانية تعديل رقم الواتساب الذي يستقبل الطلبات وتحديد رمز أو اسم العملة (مثل `ر.س`، `$`).
  - مفاتيح تبديل (Toggles) لتفعيل/تعطيل "الدفع عند الاستلام" و"التحويل البنكي / المحافظ الإلكترونية".
  - حقل نصي لكتابة وتعديل تفاصيل وأرقام الحسابات البنكية والمحافظ والمزامنة السحابية الفورية مع جدول `settings` في Supabase.
- **قسم إدارة بنر عروض الموسم (Hero Banner Settings)**:
  - تفعيل أو إخفاء البنر العلوي بالكامل بنقرة زر واحدة.
  - تخصيص نصوص الشارة الصغيرة الترويجية، العنوان الرئيسي، والنص الفرعي وحفظها فورياً في جدول `settings` في Supabase.
  - زر تفاعلي في البنر بالصفحة الرئيسية "تصفح عروض الموسم" يقوم بتصفية المنتجات والانتقال التلقائي إليها.
- **قسم إدارة الطلبات الواردة (Orders Dashboard)**:
  - جدول تفاعلي يعرض الطلبات الواردة لحظياً من جدول `orders` في Supabase.
  - عرض رقم الطلب، بيانات العميل والتواصل السريع، قائمة المنتجات، المبلغ الإجمالي، طريقة الدفع، ورقم الحوالة.
  - قائمة منسدلة لتغيير وتحديث حالة الطلب فورياً في السحابة: (`قيد المراجعة`، `تم التأكيد`، `تم التوصيل`).
  - إمكانية حذف الطلبات مع نافذة تأكيد.
- **قسم إدارة كوبونات الخصم**: نموذج مخصص لإنشاء كوبونات ترويجية بنسب مئوية محددة مع جدول لعرض الكوبونات الفعالة وإمكانية حذفها وحفظها في Supabase.
- **إدارة المنتجات الكاملة**: إضافة وتعديل وحذف المنتجات مع معاينة حية للصور وإحصائيات فورية وتصفية وبحث.
- **مزامنة فورية (Supabase Realtime & Multi-tab Sync)**: تحديث تلقائي ولحظي للطلبات والمنتجات والكوبونات والإعدادات بين جميع الأجهزة والشاشات المفتوحة.

### 6. تطبيق ويب تقدمي قابل للتثبيت على الجوال (PWA Ready)
- **قابل للتثبيت (Installable PWA)**: تحويل المتجر بالكامل إلى Progressive Web App يمكن تثبيته كأيقونة تطبيق مستقل على شاشات الجوال وأجهزة الكمبيوتر.
- **زر تثبيت أنيق وذكي**: يظهر زر تفاعلي في أعلى المتجر بعنوان *"تثبيت التطبيق على الجوال"* يتيح للمستخدم التثبيت بنقرة واحدة، ويختفي تلقائياً عند فتح التطبيق في وضع Standalone أو بعد اكتمال التثبيت.
- **ملف Manifest متكامل (`manifest.json`)**: يدعم الاتجاه من اليمين لليسار (`dir: rtl`)، وضع العرض المستقل (`standalone`)، وأيقونة عالية الدقة بدقة 512×512.
- **تسريع التصفح والتخزين المؤقت (`service-worker.js`)**: تخزين مؤقت للأصول الأساسية بتقنية *Stale-While-Revalidate* لتسريع زمن التحميل وتوفير تجربة سلسة حتى مع ضعف الاتصال.

```text

├── index.html          # الواجهة الرئيسية للمتجر (المنتجات، السلة، نافذة إتمام الطلب)

├── manifest.json       # ملف إعدادات تطبيق الويب التقدمي (PWA Manifest)
├── service-worker.js   # سكربت الكاش وتسريع التحميل في الخلفية (Service Worker)
├── icon-512.png        # أيقونة المتجر عالية الدقة (512x512) للتثبيت والـ Favicon
├── PLAN.md             # وثيقة الخطة الفنية والتطويرية للمشروع
└── README.md           # دليل المشروع والتوثيق الشامل
```

## 🚀 طريقة التشغيل

المشروع مبني بأسلوب **Zero Configuration** ولا يحتاج لتثبيت أي حزم أو خوادم معقدة:

1. قم بتنزيل أو استنساخ المستودع:
   ```bash
   git clone https://github.com/malktheery-dotcom/smart-store-ar.git
   ```
2. ادخل إلى مجلد المشروع:
   ```bash
   cd smart-store-ar
   ```
3. افتح ملف `index.html` في أي متصفح ويب حديث (Chrome, Firefox, Safari, Edge) بالنقر المزدوج عليه.
4. للوصول إلى لوحة التحكم، انقر على زر **"لوحة التحكم"** في أعلى الصفحة أو افتح ملف `admin.html` مباشرة.

## ⚙️ التخصيص والإعدادات

يمكنك تخصيص المتجر بسهولة عبر فتح ملف `script.js` وتعديل كائن الإعدادات في البداية:

```javascript
const CONFIG = {
  STORE_PHONE: "966501234567", // قم بوضع رقم هاتف المتجر بالصيغة الدولية بدون (+)
  CURRENCY: "ر.س",            // العملة المعروضة في المتجر
  PRODUCTS_KEY: "smartstore_products", // مفتاح تخزين المنتجات في LocalStorage
  CART_KEY: "smartstore_cart"          // مفتاح تخزين السلة في LocalStorage
};
```

## 🛠️ التقنيات المستخدمة

- **HTML5**: بناء هيكلي دلالي متوافق مع معايير الويب وقارئات الشاشة.
- **CSS3**: استخدام متغيرات CSS (Variables)، Flexbox، CSS Grid، وتأثيرات حركية خفيفة.
- **JavaScript (ES6+)**: كتابة كود تفاعلي نقي للتحكم بالواجهة، وإدارة الحالة (State).
- **Supabase Cloud Database**: قاعدة بيانات سحابية متكاملة لربط ومزامنة المنتجات والإعدادات والكوبونات لحظياً عبر الـ CDN.
- **WhatsApp Click to Chat API**: ربط الطلبات مباشرة بواتساب من دون الحاجة لباك إند.
- **Google Fonts (Cairo)**: طباعة عربية عصرية واضحة.
